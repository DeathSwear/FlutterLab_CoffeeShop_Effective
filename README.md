# flutter_course

Release version 1.0.0!

Project from the Flutter course.

It is a coffee shop application.
There is a page with categories and products, as well as a page of Yandex Maps, which contains all branches of the store.
When you order products, you will receive a notification.
There is support for two languages: English, Russian.

Used technologies:
scrollable_positioned_list, dio, flutter_bloc, get_it, drift, sqlite3_flutter_libs, yandex_mapkit, location, shared_preferences, firebase.

The launch procedure is standard, there are no peculiarities.
